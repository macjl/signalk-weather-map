# Weather Map roadmap

## Display forecasts directly from GRIB datasets

- [ ] Add the [Forecast Dataset Provider](https://github.com/macjl/signalk-forecast-dataset-provider) as a source alongside the Signal K Weather API. Select a GRIB dataset and display its forecast layers and available times directly on the map.

## Compare forecasts at the same valid time

- [ ] Compare two models, such as AROME and ECMWF, over the same area and forecast time.
- [ ] Compare two runs of the same model for the same valid time to see how the forecast changed between updates.
